# Руководство администратора

## Доступ в админку

Публичной регистрации нет. Первый аккаунт создаётся вручную на сервере:
```bash
npm run seed:admin -- admin@example.com 'пароль'
```
Дальше уже залогиненный администратор может добавлять других сотрудников через `/admin/users`, либо права можно менять напрямую в таблице `user_profiles`.

Вход на сайте доступен только через незаметную иконку в правом верхнем углу шапки (`/login`) — публичных ссылок на неё нет.

Самостоятельный сброс пароля по email отключён: кнопка «Забыли пароль?» на `/login` показывает контакт администратора. Сбросить пароль сотруднику может только администратор — на странице `/admin/users` кнопка «Сменить пароль» у нужного пользователя. После смены все активные сессии этого пользователя завершаются, и ему нужно войти заново с новым паролем.

## Как проверяется доступ
- сессия хранится в httpOnly cookie `novinki_session`
- `middleware.ts` не пускает на `/admin*` без сессии
- внутри admin-страниц права дополнительно проверяются через `rpc('check_admin_status')`

## Что есть в админке
- `/admin` — создание, редактирование, дублирование, архивирование и удаление товаров; массовое архивирование через чекбоксы
- `/admin/trash` — корзина и восстановление
- `/admin/archive` — архив
- `/admin/users` — роли, блокировки, смена пароля сотрудникам
- `/admin/categories` — категории и годы (для фильтров на сайте)
- `/admin/requests` — заявки от сотрудников («Сообщить о новинке»)
- `/admin/analytics` — статистика

## Карточка товара
- можно прикрепить несколько фото — они показываются каруселью в карточке на сайте
- есть отдельная листовка (PDF)
- флаг «Это новинка поставщика» включает товар в фильтр «Новинки поставщиков» на сайте
- в списке товаров видно, кто добавил и кто последний раз редактировал запись (только в админке, на сайте это не показывается)

## Быстрое добавление товаров
- **Список артикулов** (кнопка вверху админки): вставьте артикулы из письма, Excel или PDF — каждый станет отдельной карточкой с фото, названием, брендом, ссылкой, тегами и описанием с complexbar.ru. Карточки создаются в архиве (сотрудники их не видят), пока вы не нажмёте «Опубликовать» — или отметьте «Сразу показывать сотрудникам».
- **Защита от дублей**: если артикул или ссылка уже есть в базе (в том числе как вариант серии или в архиве), форма и список артикулов предупредят и предложат открыть найденную карточку.
- **Описание по характеристикам**: «Составить по характеристикам сайта» над полем «Описание» пишет описание и преимущества только по тому, что указано на странице товара (материал, размеры, серия, ПММ/СВЧ). Текст нужно просмотреть и поправить.

## Работа без сети (у сотрудников)
Сайт хранит на устройстве копию каталога и фото карточек. Без связи открывается сохранённый каталог с пометкой «Нет связи — показан каталог, сохранённый …». Каталог на сайте виден всем, поэтому копия на устройстве — то же, что видит любой посетитель. Для этого сайт должен открываться по https (или localhost).

## Если не пускает в `/admin`
Проверьте:
- существует ли запись в `sessions`
- жив ли cookie `novinki_session`
- есть ли у пользователя запись в `user_profiles`
- стоит ли `is_admin = 1`

## Картинки и листовки товаров
По умолчанию файлы сохраняются как data URL прямо в базе (`NEXT_PUBLIC_STORAGE_DRIVER=base64`) — это работает без дополнительной настройки, но база растёт пропорционально числу и размеру файлов. Если каталог станет большим, на сервере с доступом к диску можно переключиться на `NEXT_PUBLIC_STORAGE_DRIVER=filesystem` (см. [DEPLOYMENT.md](DEPLOYMENT.md)) — тогда файлы будут храниться на диске, а в базе — только путь к ним.
